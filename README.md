Ember & Thyme — a top-down rush cooking game: chop, grill, assemble and serve orders against the clock in a 3-minute shift. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys (or click to move), E or click to grab, chop, grill, assemble and serve.
